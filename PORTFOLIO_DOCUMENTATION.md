## Style Guide

### Color Palette

#### Primary Colors
- **Background**: `rgb(254, 252, 241)` - Warm cream providing soft contrast
- **Primary Accent**: `rgb(86, 151, 155)` - Professional teal for branding and accents
- **Text Primary**: `black` / `#2c3e50` - High contrast for readability
- **Text Secondary**: `#333`, `#666`, `#888` - Hierarchy through color variation

#### Accent Variations
- **Light Backgrounds**: `rgba(86, 151, 155, 0.05)` - Subtle content areas
- **Medium Backgrounds**: `rgba(86, 151, 155, 0.1)` - Card backgrounds
- **Border Colors**: `rgba(86, 151, 155, 0.2)` - Subtle separation
- **Hover States**: `rgba(86, 152, 155, 0.797)` - Interactive feedback

#### Usage Guidelines
- **Primary teal**: Use for navigation elements, buttons, headings, and brand elements
- **Background cream**: Main page background, maintains warmth while ensuring readability
- **Text hierarchy**: Black for main headings, #333 for body text, #666-#888 for secondary information
- **Accent transparency**: Use rgba variations for backgrounds and borders to maintain cohesion

### Typography

#### Font System
**Primary Font Stack**: `'Segoe UI', Tahoma, Geneva, Verdana, sans-serif`

**Rationale**: Cross-platform consistency with excellent readability across all devices. Segoe UI provides modern appearance on Windows, with reliable fallbacks for other systems.

#### Font Sizes & Hierarchy
```css
/* Hero/Main Titles */
h1: 40px - 48px (desktop) / 24px - 36px (mobile)

/* Section Headings */
h2: 36px (desktop) / 24px - 28px (mobile)

/* Subsection Headings */
h3: 24px (desktop) / 20px (mobile)

/* Small Headings */
h4, h5: 18px - 22px (desktop) / 16px - 18px (mobile)

/* Body Text */
p, li: 16px (desktop) / 14px - 16px (mobile)

/* Small Text */
.small, captions: 14px (desktop) / 12px - 14px (mobile)
```

#### Font Weights
- **Bold (700)**: Main headings, important emphasis
- **Semi-Bold (600)**: Subheadings, navigation elements
- **Medium (500)**: Secondary headings, button text
- **Normal (400)**: Body text, general content

#### Line Heights & Spacing
- **Headings**: `1.2 - 1.4` for compact, impactful appearance
- **Body Text**: `1.6` for comfortable reading experience
- **Lists**: `1.6` maintaining consistency with paragraph text

### Layout System

#### Grid Framework
**CSS Grid Primary**: Flexible, semantic layout system
```css
/* Project Grid */
grid-template-columns: 80px 1fr;
grid-template-columns: 80px 300px 1fr;

/* Gallery Grid */
grid-template-columns: repeat(3, 1fr); /* Desktop */
grid-template-columns: repeat(2, 1fr); /* Tablet */
grid-template-columns: 1fr; /* Mobile */
```

**Flexbox Secondary**: Component-level alignment and distribution
```css
/* Navigation, cards, content alignment */
display: flex;
align-items: center;
justify-content: space-between;
```

#### Container Widths
- **Full-width sections**: `95%` max-width for consistent page margins
- **Content containers**: `1000px - 1200px` max-width for readability
- **Mobile**: Full width with `15px - 20px` padding

#### Spacing System
**Consistent Scale**: Based on `5px` increments
- **Small**: `10px - 15px` - Component internal spacing
- **Medium**: `20px - 30px` - Section spacing, card padding
- **Large**: `40px - 50px` - Major section separation
- **Extra Large**: `80px+` - Hero sections, major visual breaks

### Visual Elements

#### Border Radius
- **Subtle**: `8px` - Cards, buttons, form elements
- **Medium**: `10px - 15px` - Image containers, major elements
- **Rounded**: `50%` - Profile images, icon containers

#### Shadows & Depth
```css
/* Subtle Card Shadow */
box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);

/* Hover State Shadow */
box-shadow: 0 8px 20px rgba(0, 0, 0, 0.15);

/* Element Emphasis */
box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1);
```

#### Borders
- **Subtle Separation**: `1px solid rgba(86, 151, 155, 0.2)`
- **Emphasis Borders**: `2px solid rgba(86, 151, 155, 0.3)`
- **Accent Borders**: `4px solid rgb(86, 151, 155)` - Left border emphasis

### Interactive Elements

#### Buttons
```css
/* Primary Button */
background-color: rgb(86, 151, 155);
color: rgb(254, 252, 241);
padding: 5px 15px;
border-radius: 8px;
transition: all 0.3s ease;

/* Hover State */
background-color: rgba(86, 151, 155, 0.8);
transform: translateY(-2px);
```

#### Links
- **Navigation**: Teal color with underline on hover
- **Inline**: Inherit color with subtle hover effects
- **Social Icons**: Image-based with hover transformations

#### Animations
**Timing Function**: `ease` for natural, organic feeling
**Duration**: `0.3s` for quick, responsive feedback
**Transform Properties**: `translateY()`, `scale()`, `opacity`

### Responsive Design

#### Breakpoint Strategy
```css
/* Large Tablets & Desktop */
@media (max-width: 1366px)

/* Standard Tablets */
@media (max-width: 1099px)

/* Small Tablets / Large Mobile */
@media (max-width: 949px)

/* Standard Mobile */
@media (max-width: 609px)

/* Small Mobile */
@media (max-width: 459px)

/* iPhone & Similar */
@media (max-width: 375px)
```

#### Responsive Modifications
- **Typography**: Scale down 15-25% for mobile devices
- **Spacing**: Reduce margins and padding by 20-30%
- **Layout**: Stack horizontal elements vertically
- **Images**: Maintain aspect ratios, adjust maximum widths
- **Navigation**: Transform to hamburger menu pattern

### Accessibility Guidelines

#### Color Contrast
- **AA Compliance**: All text meets WCAG 2.1 standards
- **High Contrast**: Black text on cream background provides excellent readability
- **Color Independence**: Information not conveyed through color alone

#### Typography Accessibility
- **Readable Fonts**: Sans-serif fonts for clarity across devices
- **Scalable Text**: Relative units allow user zoom without breaking layout
- **Adequate Line Height**: 1.6 line-height ensures comfortable reading

#### Interactive Accessibility
- **Focus States**: Visible keyboard navigation indicators
- **Touch Targets**: Minimum 44px touch areas for mobile
- **Alt Text**: Descriptive alternative text for all images
- **Semantic HTML**: Proper heading hierarchy and landmark elements
