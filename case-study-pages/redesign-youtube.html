Re-design YouTube Music Mobile App

UX Design • Team Project (4 members)

Project Overview

This project involved redesigning the YouTube Music mobile app to improve user experience based on comprehensive research and usability testing. Working with a team of 4 members, we conducted quantitative and qualitative research to identify pain points and created a more intuitive interface.

Interviews

Matt conducted in-depth interviews with 2 users to gain deeper insights into their music listening habits and frustrations with existing apps.

Interview Insights

Commonalities (Shared Insights)
  • Vast music library valued: Both participants appreciate the extensive library, which includes official releases, covers, and user-generated content.
  • Personalized recommendations appreciated but imperfect: Users value recommendations but want improvements in surfacing less mainstream genres.
  • Playlist engagement: Both interact with playlists—Vanessa curates her own for different moods, while Davin prefers curated ones.
  • UI improvement as a shared need: Both users agree that the user interface could be better designed to improve overall experience.
Differences (Individual Perspectives)
UI pain points:

Davin → frustrated with inconsistencies and cluttered search results (mainly due to third-party uploads).

Vanessa → wants the UI to be more visually appealing and customizable.

Device experience:

Davin → notices the mobile app is more streamlined compared to web.

Vanessa → finds experience consistent across devices.

Memorable experiences:

Davin → positive (discovering new artists via curated playlists), negative (irrelevant algorithmic recommendations).

Vanessa → positive (discovered a unique cover of a favorite song).

Switching consideration:

Davin → considered switching due to usability issues + third-party content overload.

Vanessa → never considered switching; believes YouTube Music meets all her needs.

Improvement Opportunities (User Suggestions)

Problem Analysis

Based on our research, we identified the following main problem areas:

1. User Interface Complexity

Users struggle to find basic features due to inconsistent interfaces and poor information architecture

2. Inadequate Personalization

Recommendation algorithms don't match user preferences effectively

3. Playlist Management Challenges

Creating, editing, and accessing playlists are not easy to operate

4. Inconsistencies Across Devices

Inconsistencies in functionality and interface design on different devices disrupt the continuity of the music listening experience, impacting user satisfaction

4. Presence of Third-Party Content

Too much third-party content

Problem Statement

The current iteration of YouTube Music presents several usability and functionality challenges for users. These include a cluttered and inconsistent user interface, inadequate personalization of music recommendations, challenges in playlist management, inconsistencies across devices, and issues with the presence of third-party content. As a result, users experience difficulties in navigating the app, finding relevant content, and enjoying a seamless music listening experience. There is a need to address these issues to improve user satisfaction and enhance the overall usability of YouTube Music.

Test

Usability Testing

Kate and Jiwoo conducted multiple rounds of usability testing with 2 users to validate our design decisions and iterate on the prototypes.

Test Tasks

  • Find the fast approach to search for a song – Evaluate the ease of finding and using the quick song search feature.
  • Access the EQ screen – Evaluate whether the EQ screen is easy to understand and use.
  • Access the user account screen – Evaluate ease of operation and functionality.
  • Access music chart, analytics, preference, and settings screens – Evaluate discoverability and usability of these screens.
  • Access the history screen – Evaluate usability and the ability to remove history.
  • Access the library screen – Evaluate ease of use and ability to create a new playlist.

Analysis & Findings

1. Fast Song Search

User 1: Found the new music recognition feature on the home screen; easy to locate and understand.

User 2: Accessed via search screen; liked the feature since they often try to search without knowing the song name.

2. EQ Screen

User 1: Found navigation straightforward; layout clear with identifiable sliders and buttons.

User 2: Accessed easily; features understandable but complained the EQ chart colors were unpleasant.

3. User Account Screen

User 1: Accessed effortlessly via profile icon; praised intuitive navigation and suitable icons.

User 2: Accessed easily; commented that it was better than YouTube's current version.

4. Music Chart / Analytics / Preferences / Settings

User 1: Found options on one screen; labels appropriate but organization felt illogical.

User 2: Accessed all screens; liked most, but found analytics dashboards overly complex and possibly unnecessary.

5. History Screen

User 1: Accessed via header icon or profile page; found remove history easy but screen too complex.

User 2: Accessed without barrier; appreciated remove history feature but disliked link design (too small/tap-unfriendly); suggested using a button instead.

6. Library Screen

User 1: Accessed quickly via footer; praised organized layout; creating new playlist easier than original YouTube Music.

User 2: Accessed without issues; interface simpler and clearer; create playlist button easy to operate.

Key Issues Identified

  • Unpleasant EQ chart colors
  • Layout complexity and icon choices on user account screen
  • Overly complex analytics dashboards
  • Inconsistent button/link design (links too small)

Design Improvements Implemented

  • Changed EQ chart color scheme (white, red, gray)
  • Simplified layout and icons on the account screen
  • Reduced analytics dashboards to one basic chart
  • Replaced all links with uniform buttons

Final Solution & Design Brief

Our final design addresses the identified problems through comprehensive interface improvements and enhanced user experience features, validated through iterative usability testing.

Core Solution Areas

Based on our research findings and usability testing feedback, we focused on five key improvement areas that directly address user pain points and enhance the overall YouTube Music experience.

Enhanced Search Functionality

Problem: Users struggled with finding songs and irrelevant search results

Solution: Implemented fast song search with music recognition feature, accessible from home screen and search interface

Impact: 100% task completion rate for song discovery

Streamlined Audio Controls

Problem: EQ interface was confusing with unpleasant visual design

Solution: Redesigned EQ screen with clear sliders, intuitive layout, and improved color scheme (white, red, gray)

Impact: Users found navigation straightforward and features understandable

Simplified User Account Management

Problem: Complex layout and poor icon choices in account screens

Solution: Streamlined interface design with intuitive navigation, suitable icons, and logical information architecture

Impact: Users praised the improvement over YouTube's current version

Optimized Analytics & Preferences

Problem: Overly complex dashboards and illogical screen organization

Solution: Reduced analytics to one basic chart, reorganized settings with appropriate labels and logical grouping

Impact: Eliminated user confusion while maintaining essential functionality

Consistent Interface Design

Problem: Inconsistent button/link design and poor touch targets

Solution: Replaced all links with uniform buttons, improved touch-friendly design throughout the app

Impact: Enhanced accessibility and user confidence across all screens

Improved Library Experience

Problem: Playlist creation was more complex than needed

Solution: Organized layout with clear visual hierarchy, simplified playlist creation process

Impact: Users found it easier than original YouTube Music with clearer interface

Design Principles Applied

  • Consistency: Uniform button design and interface elements throughout the app
  • Simplicity: Reduced cognitive load by streamlining complex interfaces
  • Accessibility: Improved touch targets and visual hierarchy for better usability
  • User-Centered: Every change directly addresses identified user pain points
  • Iterative: Solutions validated through multiple rounds of user testing
